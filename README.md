## 📖 这是什么

这是一个面向 **科大讯飞·星光教师超级智能体**（[sparklight.cn](https://www.sparklight.cn/)）的 Agent Skill。它以 V2.1.0（2026-10-28 发布）为准，把产品操作、版本差异与核心概念整理成 AI 可以直接调用的知识库。

装上它之后，AI 可以：

- **回答操作问题**：从入口到按钮，给出“操作路径 → 分步动作 → 易错提醒”，教师可以照着做
- **讲清核心概念**：技能、连接器、智能体、智能导师分别是什么，彼此什么关系，什么时候该用哪个
- **纠正版本误解**：分组、应用标签页、双端 H5、智能导师入口等最容易答错的地方，统一口径
- **起草培训材料**：面向教研组、全校教师、新入职教师的讲稿、图文手册、FAQ 与宣讲提纲

## 🆕 V2.1.0 更新了什么

V2.1.0 共 15 项更新，下面是与教师日常使用关系最密切的六项。完整清单见 [`reference.md`](reference.md) 第九章。

| 更新 | 对教师的实际变化 |
|---|---|
| 左侧新增「分组」 | 同一单元、同一项目的对话、资料与 AI 记忆放在一组，课标教材传一次全组复用 |
| 事务助理三合一 | 「技能」「连接器」「智能体」集中到一个管理台，学期初做一次工具清点 |
| 对话直接创建智能体 | 一句话说清定位与要求，系统自动润色、执行、注册，右侧卡片点【立即召唤】就能用 |
| 备课教学新增「应用」 | 「资源」与「应用」并列，课堂互动、班级管理、练习回收、通用工具开箱即用 |
| 双端 H5 应用上大屏 | 管理端加使用端，生成免登录链接，设有效期与授权班级后贴到教室大屏 |
| 家校沟通与个人空间 | 班级宠物支持行政班与分层班分别管理；工作室新增管理员角色；个人空间按四大专区归类 |

## 🧩 四个核心概念

这是 2.1 版新增的重点内容。很多答疑答错，不是功能不熟，而是四个概念混在一起。

| 概念 | 一句话定义 | 老师怎么用 |
|---|---|---|
| 技能 | 把一类任务的做法沉淀成标准流程，AI 按流程交付成果 | 选一个技能，AI 照着做，比如选「互动课件」就得到一份互动课件 |
| 连接器 | 给星光访问其他产品、工具与网络的授权和通道 | 连上作业本，AI 就能读到班里作业数据，不用老师导出再上传 |
| 智能体 | 有名字、有性格、有专长的 AI 伙伴，能组合技能、连接器与记忆 | 召唤一位“学情分析师”，把事交给它，它自己挑方法、连数据、记住班级情况 |
| 智能导师 | 以真实教育专家为原型的 AI 导师，复现专家的理论框架与教研流程 | 找魏锐教授一类导师型角色打磨 PBL 方案，或请专家团多视角会诊 |

### “智能导师”入口，必须这样回答

> 在星光的产品体系中，**并没有单独名为“智能导师”的一级菜单**。老师们日常所说的“智能导师”，在星光 V2.1.0 中对应的是「事务助理」→「智能体」广场中以顾问、导师、专家为定位的深度角色，以及由老师根据教学需求对话自建的专属学科/育人导师。

智能导师帮老师“想事”，按专家流程分环节引导；智能体帮老师“做事”，调用技能与连接器交付成果。当前版本智能导师不调用技能与连接器，执行类任务交给智能体。

## ✨ 效果展示

**教师问**：「智能导师在哪里？我在左边菜单找不到。」

> 星光 V2.1.0 没有单独的一级菜单“智能导师”。走「事务助理」→「智能体」，在广场里找以顾问、导师、专家为定位的深度角色（如“班级管理导师”“全学科备课顾问”），也可以直接搜专家姓名。广场里没有合适的，就在底部输入框描述需求，自建专属学科/育人导师。
>
> 如果你要找的是魏锐教授的 PBL 相关内容，同样在这个广场里找导师型角色，不需要去左侧导航翻菜单。

---

**教师问**：「我想做一个班级看板，办公室改课表，教室大屏马上显示，怎么做？」

> 这是双端 H5 教学应用，不是某个“大屏远程控制”开关。四步：
>
> 1. 在对话框说清双端分工：谁在管理端做什么，大屏显示什么，如何联动
> 2. 确认《设计蓝图》后生成，安装应用
> 3. 进应用详情页，点【···】→【生成链接】，必填【有效期】与【授权班级】
> 4. 把免登录链接贴到教室大屏，办公室电脑或手机操作管理端即可实时联动
>
> 注意：链接可以被转发，按教学周设有效期；授权范围只限所选班级。

---

**教师问**：「一个单元要传好几次课标和教材，太麻烦，有没有办法只传一次？」

> 用「分组」。点左侧「分组」标题右侧的 **[+]**，在「分组设置」里写清背景与产出要求，再挂上本地文件、云盘文件、网址链接或连接器。确认后，组内连续发起教案、课件、复习试卷，资料与 AI 记忆全组共享，不用重复投喂。
>
> 建议按“年级+学科+单元”建组，比如“八上历史·第三单元”。

## 🚀 安装与使用

### 方式一：导入技能包

1. 在 GitHub 页面点 **Code → Download ZIP**，或从 Releases 下载技能包
2. 打开支持 Agent Skill 的客户端，进入技能管理
3. 导入 ZIP，确认安装

如果客户端要求压缩包根目录直接包含 `SKILL.md`，把仓库解压后的内容重新压成 ZIP 即可。

### 方式二：手动放置

```bash
git clone https://github.com/yannkun/xunfei-sparklight-guide.git

# Windows
xcopy xunfei-sparklight-guide %USERPROFILE%\<技能目录>\xunfei-sparklight-guide /E /I

# macOS / Linux
cp -r xunfei-sparklight-guide ~/<技能目录>/xunfei-sparklight-guide
```

技能目录以客户端设置中显示的路径为准。

## 🏗️ 技术架构

```
用户提问
   │
   ▼
Skill 命中（description 匹配星光、智能导师、V2.1.0 等关键词）
   │
   ▼
SKILL.md 加载（约 246 行：速览、模块地图、四概念、实操链路、易错点）
   │
   ├── 操作细节问题 ──→ reference.md（约 549 行，按章节查阅）
   │
   └── 概念/宣讲问题 ──→ concept-guide.md（约 214 行，统一口径）
   │
   ▼
结构化回答：操作路径 → 分步动作 → 注意事项 → 场景价值
```

### 设计原则

1. **渐进式披露**：高频内容放 `SKILL.md`，操作细节放 `reference.md`，概念口径单独放 `concept-guide.md`，避免每次对话加载全量文本
2. **术语锁定**：按钮、菜单、弹窗字段与 V2.1.0 界面原文一致，不自行改写
3. **直接给路径**：回答不加“实测”“已验证”“据截图”一类来源标记，教师只需要能照着做
4. **边界诚实**：宠物分层班、工作室管理员、个人空间四大专区、小程序界面等未逐屏核对的项，明确写“以实际界面为准”，不编造按钮
5. **概念与操作分开**：操作问题查 `reference.md`，概念问题查 `concept-guide.md`，避免两套说法打架

- **星光讲师团**：培训答疑自动化，减少重复回答“在哪里点”

## ⚠️ 使用限制

- 本 Skill 提供操作指引与概念口径，不能替代星光产品本身
- 产品界面会随版本变化，遇到不一致以实际界面为准
- 智能导师的回复由 AI 基于专家理论与方法生成，不是专家本人实时回复
- 具体学科内容的生成质量取决于星光后端模型，不在本 Skill 控制范围内
- 未逐屏核对的功能会明确标注，不用推测补齐按钮名称
