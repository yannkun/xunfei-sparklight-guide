# 讯飞星光 2.0 使用指南 Skill

> 让 AI 成为星光产品的"活手册"——教师问什么，秒级给出精准操作路径。

## 📖 这是什么

这是一个面向星光平台的 Agent Skill（智能体技能），专为**科大讯飞·星光教师超级智能体**（[sparklight.cn](https://www.sparklight.cn/)）的使用培训与答疑场景设计。

它将星光 2.0 的完整产品功能（8 章 106 页官方手册 + 145 页讲师培训课件）蒸馏为结构化知识库，使 AI 能够：

- **精准回答操作问题**：任何"怎么在星光里做 XX"的问题，都能给出"入口路径 → 分步操作 → 易错提醒"的完整回答
- **覆盖全模块**：登录注册、对话管理、备课教学（教案/交互动画/课堂游戏/教学课件/命题组卷/教学应用）、家校沟通（日常表现/作业/打卡/宠物/群守护/预警/学情分析）、连接器（ima知识库/QQ机器人/自定义）、事务助理与技能、星光学苑、个人空间、设置
- **场景价值导向**：不只告诉你"怎么点"，还告诉你"为什么要这样设计""适合什么场景""和传统方式比好在哪"
- **辅助培训材料生成**：可一键生成面向不同教师群体的培训讲稿、操作手册、FAQ、微课大纲

## 🎯 为什么要做这个

### 一线痛点

| 角色 | 痛点 |
|---|---|
| 培训讲师 | 每次培训后教师问题碎片化涌来，重复回答"在哪里点""怎么操作"消耗大量精力 |
| 一线教师 | 产品功能多（6大资源类型 + 家校全链路），手册太长找不到，微信群问没人及时答 |
| 学校信息化主管 | 新教师入职、产品版本更新后需要反复组织培训，成本高 |
| 产品经理/运营 | 用户反馈问题高度重复，FAQ 维护滞后 |

### 设计思路

> **核心主张：教学成果奖首先是教学，其次才是信息化应用。**

这个 Skill 不是简单的"说明书搬运"，而是：
1. 把产品功能**锚定到教师真实工作场景**（备课→上课→课后→家校），让回答自带"为什么用"的语境
2. 把操作路径**精确到按钮名称和界面位置**，避免"大概在那里点一下"的模糊回答
3. 把易错点和版本限制**显性化**（如"群守护目前仅支持QQ群""附件为必填项"），减少踩坑

## ✨ 效果展示

### 示例对话

**教师问**：「星光的家校沟通里，怎么给多个学生批量加星？」

**Skill 驱动的回答**：

> **操作路径**：家校沟通 → 常用工作区 → 点击【日常表现】卡片 → 右上角【+ 新增学生点评】
>
> **分步操作**：
> 1. 左侧顶部下拉选择目标班级，系统自动加载学生名单
> 2. 勾选要表扬的学生（支持多选/全选/搜索定位）
> 3. 右侧点选评价标签（课堂活动获胜/团队协作出色/积极回答等，可自定义）
> 4. 调整星星数量（各类型有默认值可临时改）
> 5. 选填补充说明
> 6. 点击底部【确认加星 · 共N颗】
>
> **适用场景**：下课后或自习课，对多位学生做集中批量评价。
>
> **注意**：点评即时生效，右侧闪光榜星星会累加跳动。

---

**教师问**：「我想把星光生成的 H5 课件放到我的 PPT 里用，怎么做？」

**Skill 驱动的回答**：

> 有三种方式，按你的场景选：
>
> | 方式 | 适合谁 | 怎么做 | 注意 |
> |---|---|---|---|
> | 超链接跳转 | 任何版本 PPT | 插入→超链接→粘贴H5链接/选本地文件 | 点击会跳出PPT，需手动切回 |
> | 网页端WPS嵌入 | 用WPS网页版 | 插入→插入网页互动内容→导入H5 | 下载到本地后无法展示 |
> | 第三方插件 | 习惯桌面版PPT | 装"不坑盒子"→粘贴链接→页面内渲染 | 需提前安装插件 |
>
> **课前 5 分钟自查**：链接/文件能正常打开 → 声音/全屏/退出正常 → 已在课堂电脑试播。

## 🚀 安装与使用

### 前提条件

- 已安装支持 Agent Skill 的桌面客户端（macOS / Windows）
- 网络正常（首次加载需下载技能包）

### 安装方式

**方式一：通过 .zip 文件安装**

1. 下载本仓库的 `.zip`（GitHub 页面 → Code → Download ZIP）
2. 打开客户端 → 设置 → 技能管理 → 导入技能
3. 选择下载的 `.zip` 文件 → 确认安装

**方式二：手动放置**

```bash
# 克隆本仓库
git clone https://github.com/yannkun/xunfei-sparklight-guide.git

# 复制到客户端的技能目录（路径以客户端设置中显示的技能目录为准）
xcopy xunfei-sparklight-guide %USERPROFILE%\<技能目录>\xunfei-sparklight-guide /E /I

# 复制到客户端的技能目录（macOS/Linux）
cp -r xunfei-sparklight-guide ~/<技能目录>/xunfei-sparklight-guide
```

### 快速上手

安装后，在客户端对话框中直接提问即可触发：

- 「讯飞星光怎么生成一份教案？」
- 「家校沟通里的群守护怎么用？」
- 「怎么把星光和 ima 知识库对接？」
- 「帮我写一份面向初中数学教师的星光培训讲稿」

也可以在技能列表中点击"使用"，选择推荐问题快速开始。

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────────┐
│              Agent Runtime                           │
├─────────────────────────────────────────────────────┤
│                                                     │
│  User Query ──→ Skill Discovery (description match) │
│       │                                             │
│       ↓                                             │
│  SKILL.md loaded into context                       │
│  (产品速览 + 模块地图 + 核心流程 + 回答规范)         │
│       │                                             │
│       ↓                                             │
│  Specific question? ──→ Read reference.md           │
│  (按需查阅对应章节的详细操作步骤)                     │
│       │                                             │
│       ↓                                             │
│  Structured Response                                │
│  (操作路径 → 步骤 → 注意事项 → 场景价值)             │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 设计原则

1. **渐进式披露**：SKILL.md 只放高频概览（118行），详细操作放 reference.md（378行），避免每次对话都加载全量文本
2. **术语锁定**：所有按钮名称、入口路径与官方手册原文一致，不自行改写
3. **回答模板化**：操作类问题固定"路径→步骤→注意"结构；培训材料固定"流程+要点+易错提醒"结构
4. **边界诚实**：手册未覆盖的内容（如具体学科生成效果），如实说明不编造
